# Jeu plus marrant — contenu

Les textes ajoutés au jeu. Ceux qui existent déjà (la ligne avec les nombres de jetons, le score, les boutons) ne changent pas.

## Révélation

Une phrase taquine, tirée au hasard parmi les quatre du cas, s'affiche avant la ligne actuelle.

### Bonne réponse

- Verdict : Bien vu, tu sens le jeton cher à dix mètres.
- Verdict : Bravo, ton portefeuille te remercie.
- Verdict : Tu lis dans les pensées de l’IA, c’est un peu inquiétant.
- Verdict : Joli coup. Tu devrais facturer tes conseils.

### Raté

- Verdict : Ton portefeuille a senti passer celle-là.
- Verdict : L’IA te remercie pour ce généreux pourboire.
- Verdict : Pas grave, personne n’a rien vu. Sauf l’IA.
- Verdict : Ton intuition est partie en pause café.

### Égalité

- Verdict : Les deux langues se sont mises d’accord dans ton dos.
- Verdict : Même prix au jeton près. L’IA ne fait pas de jaloux.
- Verdict : Personne ne paie plus cher cette fois. Profites-en.
- Verdict : Égalité parfaite. Même la balance n’en revient pas.

## Fin de partie

Un titre selon le nombre de bonnes réponses, sous le score.

- Titre, 0 bonne réponse : 🪙 Mécène des jetons
- Titre, 1 bonne réponse : 🧳 Touriste du jeton
- Titre, 2 bonnes réponses : 🧮 Apprenti compteur
- Titre, 3 bonnes réponses : 📒 Comptable du dimanche
- Titre, 4 bonnes réponses : 🔍 Fin limier du jeton
- Titre, 5 bonnes réponses : 🏆 Radin du jeton certifié
